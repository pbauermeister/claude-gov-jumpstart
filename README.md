# claude-gov-jumpstart

![status](https://img.shields.io/badge/status-experimental-orange)
![built with](https://img.shields.io/badge/built_with-Claude_Code-purple)
![license](https://img.shields.io/badge/license-TBD-lightgrey)

A kit to retrofit AI-augmented engineering **governance** into a coding project — the way humans and the AI agent collaborate (process, attestation, traceability, ceremonies). It does **not** prescribe technology, architecture, language, framework, or domain — those remain the host project's choice. The kit shapes _how_ work happens; the host project owns _what_ gets built.

The kit ships Claude Code conventions (`CLAUDE.md`), ceremonies (`CEREMONIES.md`), a charter, a devlog standard, and pre-configured hooks. Installation, file inventory, and the adaptation checklist live in [`GOVERNANCE-KIT.md`](GOVERNANCE-KIT.md) — a transient document that is deleted once adaptation is complete.
