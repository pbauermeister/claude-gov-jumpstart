A kit to retrofit AI-augmented engineering governance into a coding project.

The kit ships Claude Code conventions (`CLAUDE.md`), ceremonies (`CEREMONIES.md`), a sample charter, a devlog standard, and pre-configured hooks. Installation, file inventory, and the adaptation checklist live in [`GOVERNANCE-KIT.md`](GOVERNANCE-KIT.md) — a transient document that is deleted once adaptation is complete.

> This README is a placeholder. After the kit is retrofitted into a host project, replace this file with the host project's own README.
